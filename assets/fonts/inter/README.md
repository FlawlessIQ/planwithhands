# Inter Font Files

Please download the following Inter font files from https://fonts.google.com/specimen/Inter and place them in this directory:

- Inter-Regular.ttf (weight: 400)
- Inter-SemiBold.ttf (weight: 600) 
- Inter-Bold.ttf (weight: 700)

These static font files ensure the app can build offline when GoogleFonts service is unavailable.
