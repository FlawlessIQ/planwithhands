How Hands Works

Configure once, repeat across locations, and get hands on every task.

Start free trialExplore features

Manager / Admin flow

Add locations, define shifts and roles, attach checklists, invite users, and centralize documents. Then go live with metrics.

1

Sign up

Create your organization and unlock the dashboard.

2

Log in

Access the admin tools to configure your setup.

3

Add locations

Create each store/venue to keep reporting clean.

4

Define shifts & roles

For each location, add the shifts you run and which roles use them.

5

Create checklists & assign

Attach checklists (with a set number of tasks) to relevant shifts.

6

Add users

Invite managers and staff—invites prompt mobile app download.

7

Upload training & procedures

Centralize SOPs/recipes so everyone sees the latest version.

8

Go live with metrics

Monitor completion, view photos/notes, and spot misses in real time.

9

Message your team

Send announcements to all staff, roles, or locations (push if enabled).

Staff flow

Mobile-first workflow: complete tasks, add photos and notes, review training, and receive announcements.

1

See your tasks

Open the app to view current shift checklists and what’s due now.

2

Complete with photos/notes

Upload photos, add context, or explain if something can’t be completed.

3

Review training & procedures

Access the latest SOPs from your phone—no binders needed.

4

Receive announcements

Keep aligned with messages from management.
